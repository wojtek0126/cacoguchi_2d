# Monsters from DOOM vs. Aliens

A Unity game about a DOOM monster defending its dimension from an alien invasion.

## Status

**Playable prototype — unfinished.**

The game can be played, but some features are incomplete or not yet implemented:

- HP and SP bars are intentionally hidden.
- There is no ending screen, level progression, or return-to-menu option. After defeating all enemies, close the game manually.
- Some enemy types, including the mine-deploying UFO, are not implemented.
- The scripts need refactoring.

## How to play

1. Download all ZIP files provided for the game.
2. Extract them into the same directory, keeping the files together.
3. Run the game’s `.exe` file.
4. Click **Start** to enter the game.

## Controls

- **WASD** or **Arrow keys** — Move
- **Space** — Shoot projectiles
- **X** — Dump loads

## Gameplay

- The player has **HP** (hit points) and **SP** (poo points).
- Eat dead zombies to restore HP and SP.
- Zombies killed with poo cannot be eaten.
- You cannot dump loads when SP is empty.
- UFOs can only be defeated with poo.

## About

This is a personal Unity project. It gave me hands-on experience exploring game mechanics, player behavior, and testing a playable build.
